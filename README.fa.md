# صدور و تمدید گواهی Wildcard با آروان‌کلاد

اگر DNS دامنه‌تان روی آروان‌کلاد است، این اسکریپت روی اوبونتو برای هر دامنه یک گواهی Wildcard از Let’s Encrypt می‌گیرد و آن را خودکار تمدید می‌کند. اگر پاسارگارد را با تنظیمات پیش‌فرض نصب کرده‌اید، اسکریپت گواهی‌ها را در پوشه‌ای می‌گذارد که پنل به آن دسترسی دارد.

## نصب سریع

برای شروع، این دستور را در ترمینال سرور اوبونتو بزنید.

<div dir="ltr">

```bash
curl -fsSL https://raw.githubusercontent.com/mmdkevin/arvan-wildcard-ssl/main/install.sh | bash
```

</div>

فرمان بالا اسکریپت نصب را از GitHub می‌گیرد و اجرا می‌کند. اگر می‌خواهید قبل از اجرا کد را بخوانید، هر دو فایل در ریپو هستند. [اسکریپت نصب](install.sh) · [اسکریپت صدور و تمدید](arvan_ssl.py)

### قبل از شروع

- روی سرور باید `systemd` و `curl` در دسترس باشند. فرمان نصب را با کاربر `root` یا کاربری که دسترسی `sudo` دارد اجرا کنید. نصب خودکار روی AMD64 و ARM64 کار می‌کند.
- DNS دامنه‌ها باید در آروان‌کلاد مدیریت شود.
- در پنل آروان یک کلید API بسازید که بتواند رکوردهای DNS این دامنه‌ها را ایجاد و حذف کند. [مدیریت کلیدهای API آروان](https://npanel.arvancloud.ir/profile/api-keys)

اسکریپت اول تعداد دامنه‌ها را می‌پرسد، بعد نام هر دامنه و در آخر کلید API را می‌گیرد. نام دامنه را مثل `example.com` وارد کنید. گواهی هم خود `example.com` را پوشش می‌دهد و هم زیردامنه‌های یک‌سطحی مثل `panel.example.com`. برای پوشش نام‌هایی مثل `api.dev.example.com`، دامنهٔ `dev.example.com` را هم جداگانه وارد کنید.

Let’s Encrypt مالکیت دامنه را از طریق DNS تأیید می‌کند. این روش DNS-01 نام دارد. با ادامهٔ نصب، شرایط صدور گواهی Let’s Encrypt را می‌پذیرید. [راهنمای DNS-01](https://letsencrypt.org/docs/challenge-types/#dns-01-challenge) · [شرایط Let’s Encrypt](https://letsencrypt.org/repository/)

## مسیر گواهی‌ها

در پایان، اسکریپت مسیر کامل گواهی و کلید خصوصی را در ترمینال نشان می‌دهد. برای دامنهٔ `example.com`، مسیر پوشه به شکل زیر است.

| نوع نصب | پوشهٔ گواهی برای `example.com` |
| --- | --- |
| اوبونتو | `/var/lib/arvan-wildcard/certs/example.com/` |
| نصب پیش‌فرض پاسارگارد | `/var/lib/pasarguard/arvan-certs/example.com/` |

`fullchain.pem` فایل گواهی و زنجیرهٔ آن است. `privkey.pem` کلید خصوصی TLS است. بعد از تمدید هم می‌توانید از همین دو مسیر استفاده کنید.

## استفاده در اینباند TLS پاسارگارد

در نصب پیش‌فرض Docker پاسارگارد، پنل به پوشهٔ `/var/lib/pasarguard` دسترسی دارد. اگر گواهی‌ها را با نسخهٔ قدیمی اسکریپت گرفته‌اید، فرمان نصب را دوباره اجرا کنید. وقتی سؤال `Change the saved configuration?` را دیدید، **Enter** بزنید تا اسکریپت با همان تنظیمات، فایل‌های موجود را به مسیر پاسارگارد منتقل کند. [تنظیمات Docker پاسارگارد](https://github.com/PasarGuard/panel/blob/main/docker-compose.yml)

در تنظیمات اینباند، `streamSettings.security` را روی `tls` بگذارید. نمونهٔ زیر را در فهرست `streamSettings.tlsSettings.certificates` قرار دهید و در هر دو مسیر، `example.com` را با دامنهٔ خودتان عوض کنید. [راهنمای تنظیم هستهٔ پاسارگارد](https://docs.pasarguard.org/fa/panel/core/)

<div dir="ltr">

```json
{
  "certificateFile": "/var/lib/pasarguard/arvan-certs/example.com/fullchain.pem",
  "keyFile": "/var/lib/pasarguard/arvan-certs/example.com/privkey.pem"
}
```

</div>

اگر اینباند روی یک نود جداست، هر دو فایل باید روی همان نود برای Xray قابل خواندن باشند.

## تمدید خودکار

`systemd` هر روز اسکریپت را برای بررسی گواهی‌ها اجرا می‌کند. وقتی نوبت تمدید برسد، فایل‌های تازه در همان مسیرهای قبلی قرار می‌گیرند. برنامه‌ای که از گواهی استفاده می‌کند، ممکن است برای خواندن نسخهٔ تازه به بارگذاری مجدد نیاز داشته باشد.

### وضعیت تایمر

<div dir="ltr">

```bash
systemctl list-timers arvan-wildcard-renew.timer
```

</div>

### دیدن گزارش تمدید

<div dir="ltr">

```bash
sudo journalctl -u arvan-wildcard-renew.service -n 50 --no-pager
```

</div>

### توقف تمدید یک دامنه

برای توقف تمدید، کل پوشهٔ گواهی همان دامنه را حذف کنید. اگر بعداً خواستید دامنه را دوباره اضافه کنید، فرمان نصب را اجرا کنید، گزینهٔ تغییر تنظیمات را بزنید و فهرست کامل دامنه‌هایی را وارد کنید که می‌خواهید تمدید شوند.

## کلید API و کلید خصوصی

کلید API موقع تایپ روی صفحه دیده نمی‌شود. اسکریپت آن را در فایل `/etc/arvan-wildcard/config.json` روی خود سرور ذخیره می‌کند و دسترسی فایل محدود به `root` است. فایل تنظیمات و کلیدهای خصوصی را خارج از ریپو نگه دارید.

## رفع خطا

| مشکل | راه بررسی |
| --- | --- |
| آروان‌کلاد درخواست DNS را رد می‌کند | در پنل آروان بررسی کنید که کلید API برای همان دامنه مجوز مدیریت رکوردها را دارد. |
| تأیید DNS کامل نمی‌شود | بررسی کنید نام‌سرورهای دامنه روی آروان‌کلاد تنظیم شده باشند. نام دامنه‌ای را که خطا داده می‌توانید در گزارش تمدید پیدا کنید. |
| پاسارگارد فایل گواهی را پیدا نمی‌کند | مسیر واردشده در اینباند را با مسیر چاپ‌شده در ترمینال مقایسه کنید. سپس از داخل کانتینر یا روی نودی که Xray اجرا می‌شود، دسترسی به فایل را بررسی کنید. |

اگر مشکل ادامه داشت، نسخهٔ اوبونتو و چند خط مربوط به خطا را در GitHub بفرستید. پیش از انتشار، اطلاعات محرمانه مثل کلید API را از گزارش پاک کنید. [ثبت مشکل در GitHub](https://github.com/mmdkevin/arvan-wildcard-ssl/issues)
